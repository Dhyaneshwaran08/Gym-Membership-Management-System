# Gym Membership Management System

## Project Overview
The Gym Membership Management System is a Python-based mini project developed to manage gym member details, service costs, billing, membership categories, and benefit eligibility.

This project demonstrates the practical implementation of core Python programming concepts through a simple gym management scenario.

## Features
- Member information management
- Membership plan and status tracking
- Service cost management
- Additional service handling
- Service cost summary and analysis
- Registration charge calculation
- Discount calculation
- GST calculation
- Final bill generation
- Membership category classification
- Member benefit eligibility
- Final member summary

## Python Concepts Used
- Variables and Data Types
- User Input and Output
- Lists
- Tuples
- Dictionaries
- For Loops
- While Loops
- Nested Loops
- Conditional Statements
- Nested Conditions
- Break and Continue
- String Operations
- Arithmetic Operators
- Relational Operators
- Logical Operators
- Bitwise Operators
- Indexing and Slicing
- Variable Swapping

## Project Workflow
1. Collect member information
2. Record service costs
3. Validate service cost inputs
4. Process additional services
5. Store and analyze service data
6. Calculate registration charges and discounts
7. Calculate GST and final bill amount
8. Classify the member category
9. Check benefit eligibility
10. Display the final member summary
